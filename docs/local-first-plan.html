CachellaLocal-first implementation plan · 9 October 2026

Your knowledge.
On your computer.

A Windows and macOS enterprise desktop application with local inference, searchable evidence and measurable cache reuse.

Current decision: Tauri 2 + React/TypeScript, a Rust native layer, SQLite and llama.cpp. Evaluate a 1–4B quantized generation model on consumer hardware. Local caching uses the inference engine’s built-in features. LMCache remains an optional enterprise-server integration.

Product contract

Import text, documents, images, audio and video. Search across modalities, inspect the original evidence and ask grounded questions with page or timestamp citations. Store files, indexes, settings and models locally. Network activity must be explicit, with model setup and optional remote enterprise inference separately disclosed.

Deliver in verified increments while retaining the full multimodal objective. An implementation limited to text is an intermediate state. Each view must state which formats and runtime features are actually available.

Execution sequence

  1. Build desktop shell and native storage boundary with text ingestion, library, search and source inspection.
  2. Connect a local llama.cpp process; validate health, model identity, request limits and evidence-only fallback.
  3. Add model installation, checksum verification, lifecycle management and offline restart behavior.
  4. Prove multimodal embedding support; add document parsing, media segmentation, timestamps, thumbnails and resumable jobs.
  5. Add cache measurement and invalidation; compare identical cold and warm workloads.
  6. Review security and concurrency independently; package desktop builds and run acceptance tests.

Hardware and cost

Use a 16 GB Windows laptop as the intended baseline, with 8 GB considered only after measured memory checks. The development Mac has 36 GiB. Model weights, KV cache, embedding processes and UI compete for memory. The optional one-model mode keeps at most one Cachella-managed engine loaded, switching between search and answers after each role has been started once per session. Stop disables automatic resumption for that role. Switching adds startup time and discards the stopped engine’s prompt cache. This residency policy provides no fixed RAM guarantee; whole-app measurements remain required.

Measured prototype: Qwen3-1.7B Q4_K_M through llama.cpp plus EmbeddingGemma 2 Q8. Two M3 Pro runs observed 1.488–1.507 GiB of sampled combined process footprint, with clean mapped memory, the desktop webview and the OS outside that metric. This does not establish a minimum RAM requirement. For an identical 1,365-token prefix, generation-only median response latency was 1,624.5 ms with reuse disabled and 763.0 ms with reuse enabled. These are local llama.cpp observations; LMCache was absent. Method, raw results and limitations.

Core local inference has no recurring hosting bill. Electricity, hardware, signing and distribution are separate costs. Fly.io is optional for a future service and must stay below the user’s $10 monthly budget if introduced. No cloud resources are provisioned by this plan.

Enterprise boundary

Local file access is user initiated. Keep the rendering layer free of arbitrary filesystem and shell access. Bind model servers to loopback and use an application-owned credential for a managed server. Prevent prompts and document contents from reaching remote endpoints by default. Source documents are untrusted data; the model has no tools or authority to execute instructions.

An optional enterprise-server adapter may later connect to vLLM + LMCache under explicit policy. That option needs tenant-aware permissions, authentication, transport security and independent benchmarks. Local prompt-cache results must never be presented as LMCache measurements.

Delivery evidence

The macOS release has native multimodal, lifecycle, context-limit recovery and long-context measurements. Windows execution and the intended 16 GB hardware check remain pending. The test package references separately downloaded models and has no distribution signature. Current package, evidence and remaining delivery gates.

Acceptance

  • Persistent imported content survives a native-app restart; deletions remove searchable chunks and invalidate cached answers.
  • Every citation resolves to an actual supplied source; absent evidence yields an explicit abstention.
  • One actual model completes a grounded query with a quantized checkpoint; timings come from measured execution.
  • Four modality fixtures retrieve the expected evidence, including audio tracks in videos.
  • Windows and macOS verification are reported separately. Cross-platform source alone does not prove Windows runtime behavior.
  • All relevant tests, type checks and lint checks pass; risk-bearing changes receive independent review.
